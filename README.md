# Road Rush

Kids road-trip arcade. Drive across valleys and worlds toward Grandma’s house — dodge obstacles, grab coins and boosts, race to the finish!

## Play

**Live:** https://sakhamoori.github.io/RoadRush/

## Controls

- **Hold →** to drive · **Space / ↑** = jump · **←** = back up
- **Touch:** hold GO pedal, tap JUMP

## Features (v1)

- Lobby with title **Road Rush**, HUD (Lv, hearts, score, distance), Start / Shop / Rebirth / How to play
- 10 worlds · 50 levels listed (World 1 playable; others locked UI)
- Playable **Sunny Valley** — side-scroll drive with jump, coins, obstacles, boosts, finish flag
- Simple Shop + Rebirth panels

## Develop

```bash
npm install
npm run dev
npm run build
```
